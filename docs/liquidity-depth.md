# Bounded ± price depth

Bounded depth supplements `activeLiquidityUsd`; it never replaces it or total TVL. `depth1PctUsd`, `depth2_5PctUsd`, `depth5PctUsd` and `depth10PctUsd` describe liquidity within fixed bands around the current token1/token0 price. All values use independently timestamped token USD prices. Observations are stored in `depth_observations` separately from the existing snapshots, refreshed no more often than the configured interval (default ten minutes) unless the active bin or V3 liquidity/price changes materially. A partial bin-array or tick-bitmap read yields null, never a smaller-looking fabricated total.

**Meteora DLMM:** Read the actual bin arrays covering each band using the [official DLMM SDK's bin-array derivation and decoder](https://github.com/MeteoraAg/docs/blob/main/developer-guides/dlmm/typescript-sdk/reference.mdx). For each bin whose price `P_bin / P_active = (1 + binStep / 10,000)^(binId - activeId)` falls within a band, add its raw token X and Y balances after decimal conversion: `Σ(X_bin × USD_X + Y_bin × USD_Y)`. Absent uninitialized arrays count as empty; malformed or incomplete array reads do not. This is real deposited bin inventory in the band, not just the active bin.

**Uniswap V3 / PancakeSwap V3:** Read all `tickBitmap` words over the widest band and the initialized ticks' `liquidityNet` at a pinned block. Starting at current `L` and `sqrt(P)`, walk upward, adding `liquidityNet` when crossing a tick; walk downward, subtracting it. At each segment, token0 available on an upward price move is `ΔX = L(1/√P_start − 1/√P_end) / 10^decimals0`; token1 available on a downward move is `ΔY = L(√P_start − √P_end) / 10^decimals1`. The band's USD depth is `ΣΔX × USD_0 + ΣΔY × USD_1`. Reversed displayed token order uses reciprocal price bounds. This follows [Uniswap's tick and bitmap state model](https://developers.uniswap.org/docs/sdks/v3/guides/pool-data) and measures two directional amounts available before leaving the band. It is not a single exact-tick virtual reserve, a trade quote including fees/slippage/gas, or the deposited value of LP positions; the two directions are alternative paths, so their sum is a comparison statistic rather than executable in one trade.

Depth is capped at 32 DLMM arrays, 24 V3 bitmap words and 512 initialized ticks per pool by default. Pools exceeding caps remain unavailable. `feeEfficiencyDepth* = measuredOrOfficialFees / depth5PctUsd` and `volumeDepthRatio* = volume / depth5PctUsd` are null when depth is absent or zero. For EVM, these new ratios require a complete event-derived window; they do not substitute GeckoTerminal's discovery volume. Current capital is compared with a past activity window; these ratios are not yields or position returns.
