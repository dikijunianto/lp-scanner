# Historical price backfill

Version `sprint5-v1` runs only in the background worker. Recent unpriced EVM swap events go first; attempted unavailable events wait before retry, allowing older events to progress. The worker processes at most `PRICE_BACKFILL_EVENTS_PER_CYCLE` events and `PRICE_BACKFILL_CALLS_PER_CYCLE` upstream calls per cycle. `PRICE_CALLS_PER_MINUTE` caps calls by chain. Stored price observations are reused before any network request.

The historical source adapter returns `priceUsd`, the source's own `sourceTimestamp`, `observedAt`, source name, confidence, and resolution. Current prices from DefiLlama and CoinGecko stay independent; the historical adapter currently uses DefiLlama Coins. Add another historical source by implementing `HistoricalPriceSource`. Five-minute bucket keys contain chain, token address, bucket, and source. Positive and negative lookup results persist, so repeated swaps in the same asset/bucket do not refetch. A quote is accepted only if its source timestamp is no later than the swap and at most five minutes old. The bucket is a request/cache unit, not a fabricated exact price timestamp. Resolution is stored as `5M` and the original source timestamp remains visible in `price_observations`.

Only the positive input token of each swap needs a USD quote. `volumeUsd = inputTokenBaseUnits / 10^decimals × priceUsd`. Gross fee is volume times pool fee tier; Pancake's emitted protocol fee is subtracted for LP fees by existing `swapUsd` logic. Missing quotes leave volume, fee and fee-efficiency null. Existing non-null historical values are not overwritten. Newly filled events record source, resolution, reason (cleared on success), and algorithm version. Their minute bucket is rebuilt transactionally. Fee-window updates follow the ordinary fee-indexing path.

Missing-data reasons distinguish `NO_TOKEN_PRICE`, `STALE_PRICE`, `FUTURE_PRICE`, `PROVIDER_FAILURE`, `UNSUPPORTED_ASSET`, `VALUATION_ERROR`, and `PRICE_REQUEST_BUDGET`. Older unknown rows remain `HISTORICAL_PRICE_UNAVAILABLE` until attempted. The current source may omit thin tokens or rate-limit; one source cannot establish independent price consensus. A historical quote is neither an executable price nor a minute-by-minute candle.
